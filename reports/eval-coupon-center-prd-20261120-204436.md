## 复现方式

```bash
$env:ATP_LLM_MODE='deepseek'
python run.py eval --prd coupon-center-prd --golden data/golden/coupon-golden.json --sweep --judge llm
```

> 指标定义：Match Rate = 命中的基准点 / 基准点总数（一对一贪心匹配，默认阈值 0.55，敏感性见上表）；
> Fidelity = 启发式代理：命中对里关键数字/状态是否被带入，属保守下限，接入 `--judge llm` 后改为 1–5 分制。
